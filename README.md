# Enhancing Network Security Resilience Using Machine Learning

## Overview

This graduation project explores the use of Machine Learning techniques to enhance the resilience of communication networks against security attacks.

The project focuses on detecting and analyzing malicious network behavior and evaluating the ability of Machine Learning models to improve network security and resilience.

## Technologies

* Python
* Machine Learning
* NS-3
* Network Security
* V2X Communication

## Project Goals

* Analyze the impact of security attacks on network performance.
* Investigate Machine Learning techniques for attack detection.
* Evaluate network resilience under different attack scenarios.
* Compare network performance before and after applying the proposed approach.
